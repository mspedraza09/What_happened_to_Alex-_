Persistencia + systems
What Happened to Alex

El flujo del proyecto conecta la interfaz del jugador con un sistema de guardado propio. El jugador se registra o inicia sesión, el progreso se guarda por usuario y las escenas consultan ese estado para desbloquear pistas, apps y el diario.

$ Login/Register → StorageEngine → data.log + index.bin → GameManager → Apps → Pistas → Diario
← → navegar · P imprimir

flujo persistente

Ciclo: guardar, leer y recuperar

Guardar

Se agrega una línea JSON al final de data.log y se guarda su offset.

Leer

La HashTable resuelve la clave a un offset y RecordStore lee esa línea exacta.

Recuperar

Si index.bin está dañado, Recovery reconstruye el índice recorriendo todo el log.

clave progress:alex:fase → offset 184 → {"data":2}

RecordStore: data.log append-only

RecordStore.gd

Controla data.log. Es append-only: cada cambio agrega una nueva línea JSON y devuelve el offset donde quedó.

RecordStore.gd
01 class_name RecordStore # clase del log de registros
02 extends RefCounted
03 
04 var filepath: String
05 
06 func _init(path: String) -> void:
07 	filepath = path
08 	if not FileAccess.file_exists(filepath):
09 		var f = FileAccess.open(filepath, FileAccess.WRITE)
10 		f.close()
11 
12 func append(record_type: String, key: String, data: Variant) -> int: # agrega un registro al final
13 	var record: Dictionary = { # estructura que se guardará
14 		"type": record_type, # categoría del registro
15 		"key": key, # clave del dato
16 		"data": data # contenido guardado
17 	}
18 	var line: String = JSON.stringify(record) + "\n" # convierte el registro en JSON por línea
19 	var f = FileAccess.open(filepath, FileAccess.READ_WRITE)
20 	f.seek_end() # mueve el cursor al final
21 	var offset: int = f.get_position() # guarda posición de cada registro
22 	f.store_string(line) # escribe la línea en data.log
23 	f.close()
24 	return offset # devuelve el offset del registro
25 
26 func read_at(offset: int) -> Variant: # lee un registro desde su offset
27 	if not FileAccess.file_exists(filepath):
28 		return null
29 	var f = FileAccess.open(filepath, FileAccess.READ)
30 	f.seek(offset) # se posiciona en la línea buscada
31 	var line: String = f.get_line() # obtiene una línea JSON
32 	f.close()
33 	if line.is_empty():
34 		return null
35 	var result = JSON.parse_string(line)
36 	if result == null:
37 		return null
38 	return result
39 
40 func iter_all() -> Array: # recorre todo el log
41 	var results: Array = []
42 	if not FileAccess.file_exists(filepath):
43 		return results
44 	var f = FileAccess.open(filepath, FileAccess.READ)
45 	while not f.eof_reached(): # avanza hasta el final del archivo
46 		var offset: int = f.get_position() # guarda posición de cada registro
47 		var line: String = f.get_line() # obtiene una línea JSON
48 		if line.is_empty():
49 			continue
50 		var result = JSON.parse_string(line)
51 		if result != null:
52 			results.append([offset, result])
53 	f.close()
54 	return results

Recovery: reconstrucción del índice

Recovery.gd

Lee todos los registros de data.log, conserva la última versión de cada clave e ignora las claves cuyo último registro sea delete.

Recovery.gd
01 class_name Recovery # clase para reconstruir el índice
02 extends RefCounted
03 
04 var record_store: RecordStore # acceso a data.log
05 var index_store: IndexStore # acceso a index.bin
06 
07 func _init(rs: RecordStore, ist: IndexStore) -> void:
08 	record_store = rs
09 	index_store = ist
10 
11 func rebuild(hash_table: HashTable) -> int: # reconstruye índice desde el log
12 	var temp_list: Array = []
13 	for entry in record_store.iter_all():
14 		var offset: int = entry[0]
15 		var record: Dictionary = entry[1]
16 		var key: String = record.get("key", "")
17 		var record_type: String = record.get("type", "")
18 		if key.is_empty():
19 			continue
20 		var is_delete: bool = (record_type == "delete") # detecta tombstones
21 		var found: bool = false
22 		for i in range(temp_list.size()):
23 			if temp_list[i][0] == key:
24 				temp_list[i] = [key, offset, is_delete]
25 				found = true
26 				break
27 		if not found:
28 			temp_list.append([key, offset, is_delete])
29 	var count: int = 0
30 	for item in temp_list:
31 		if not item[2]:
32 			hash_table.put(item[0], item[1])
33 			count += 1
34 	index_store.save(hash_table) # guarda el índice reparado
35 	return count # devuelve cantidad reconstruida

HashTable parte 1: buckets, hash y put

HashTable.gd

La tabla hash convierte claves en buckets. Si un bucket está ocupado, usa chaining con listas enlazadas y ahora también soporta rehash automático cuando el load factor supera 0.7.

HashTable.gd
01 class_name HashTable # tabla hash manual
02 extends RefCounted
03 
04 var buckets: Array # arreglo de buckets
05 var bucket_count: int # tamaño de la tabla
06 var size: int
07 var collisions: int
08 
09 func _init(initial_capacity: int = 64) -> void:
10 	bucket_count = max(initial_capacity, 1)
11 	buckets = []
12 	for i in range(bucket_count):
13 		buckets.append(null)
14 	size = 0
15 	collisions = 0
16 
17 func _hash(key: String) -> int: # convierte clave en índice
18 	return abs(key.hash()) % bucket_count # calcula bucket válido
19 
20 func put(key: String, offset: int) -> void: # inserta o actualiza clave
21 	var index: int = _hash(key)
22 	var entry = buckets[index]
23 	if entry == null:
24 		buckets[index] = HashEntry.new(key, offset)
25 		size += 1
26 		return
27 	var current = entry
28 	while current != null: # recorre cadena de colisión
29 		if current.key == key: # encuentra nodo a borrar
30 			current.offset = offset # conserva offset más reciente
31 			return
32 		if current.next == null:
33 			break
34 		current = current.next
35 	current.next = HashEntry.new(key, offset) # agrega al final de la cadena
36 	collisions += 1
37 	size += 1
38 
39 func get_offset(key: String) -> int: # busca offset por clave
40 	var entry = buckets[_hash(key)]
41 	while entry != null:
42 		if entry.key == key:
43 			return entry.offset
44 		entry = entry.next
45 	return -1 # indica clave no encontrada
46 
47 func delete(key: String) -> bool:
48 	var index: int = _hash(key)

HashTable parte 2: buscar, borrar, exportar

HashTable.gd

Aquí se buscan offsets, se eliminan claves, se exportan pares y se realiza el rehash dinámico duplicando buckets y reinsertando todas las claves.

02 	if entry == null:
03 		return false

optimización

Rehash automático

Problema

Con demasiadas claves y pocos buckets aumentan las colisiones y las búsquedas se vuelven más lentas.

Solución

Cuando el load factor supera 0.7 la tabla duplica la cantidad de buckets y redistribuye todas las claves.

Resultado

Las operaciones put() y get_offset() mantienen complejidad promedio cercana a O(1).

$ load_factor = size / bucket_count → if load_factor > 0.7 → _rehash(bucket_count * 2)

Resumen del funcionamiento

Idea central

El proyecto no depende de una base de datos externa. Implementa su propio sistema de persistencia usando un log append-only, una tabla hash en memoria, un índice persistente y recuperación automática.

$ save(key, data) → data.log → offset → HashTable → index.bin
$ get_data(key) → HashTable → offset → read_at(offset) → data
